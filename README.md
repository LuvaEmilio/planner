# Planner

Persoonlijke planner voor school (Saxion-rooster), werk, afstuderen en uren.
Werkt als app op iPhone en laptop, ook offline. Gegevens staan op het apparaat en gaan
versleuteld (AES-256, met je eigen wachtwoord) naar een privé GitHub-repo om apparaten gelijk te houden.

Deze repo bevat alleen de app, geen persoonlijke gegevens.
